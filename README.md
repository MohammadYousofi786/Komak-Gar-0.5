# Komak-Gar-0.5

Komak-Gar-0.5 is an online shopping and tailoring management system with two main parts: an online shopping platform and a digital tailoring management system.

## Features

### Online Store

- Product browsing and categories
- Product details
- Shopping cart
- Online order submission
- Customer information management

### Tailoring Management System

- Customer information management
- Men's and women's tailoring modes
- Measurement calculations
- Tailoring pattern visualization
- Customer data storage

### Order Management

- Local order management system
- Order status updates
- Admin order panel

## Product Categories

- Men's Clothing
- Women's Clothing
- Kids' Clothing
- Jewelry & Accessories

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Python
- JSON
- LocalStorage
- HTML Canvas

## Project Structure

The project is organized into several sections, including the online store, tailoring management system, order management, server files, stylesheets, data, and images.

## Project Status

🚧 **Under Development**

Komak-Gar-0.5 is an ongoing project, and new features and improvements will be added over time.
