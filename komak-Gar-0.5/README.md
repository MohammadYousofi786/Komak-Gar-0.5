# Tailoring Management System

A web-based tailoring project focused on simplifying clothing cutting and making basic tailoring calculations more accessible, including for people with little tailoring experience.

## Overview

This project started from a simple database idea while I was working as a tailor during high school. It later developed into a web application as I learned programming step by step.

Because I did not have access to a computer at the beginning, I built and tested the project using only my mobile phone. The project is still under development, but it has been the most important part of my learning journey and has strengthened my interest in Information Technology.

## Current Features

- Clothing-cutting assistance
- Basic tailoring calculations
- Customer measurement management with local archive
- Product browsing and shopping cart
- Order management through a local Node.js API
- Payment method and payment-status records
- Requested delivery date tracking
- Admin order-status management

## Planned Features

- Improved user interface
- Additional tailoring tools
- Persistent customer data shared with the server
- Online payment integration

## Technologies

- HTML
- CSS
- JavaScript
- Node.js, Python, and PowerShell server options

## Project Structure

- `html/`: website pages
- `css/`: stylesheets
- `js/`: browser JavaScript
- `node/`: Node.js server
- `python/`: Python server
- `powershell/`: PowerShell server
- `assets/images/`: product and brand images
- `data/`: JSON data and product catalogs

## Current Status

This project is under active development. The current focus is improving the clothing-cutting system before expanding the management features.

## Run Locally

1. Install Node.js.
2. Open a terminal in the project folder.
3. Run `npm start` (the Node.js server is in `node/server.js`).
4. Open `http://127.0.0.1:3000/` in a browser.
5. Open `/admin.html` to manage orders and payment statuses. The pages are stored in `html/`, but the server keeps these short URLs working.
